# 🤫 Shh-eat Project

> **"회의는 계속. 간식도 조용히."**

Shh-eat은 회의와 업무 중 소리·가루·냄새 부담 없이 조금씩 즐길 수 있는 **직장인용 저소음 오피스 스낵 브랜드**입니다.

## 🎯 프로젝트 목표
- **타깃**: 조용한 업무 환경에서 일하는 25~39세 직장인
- **핵심 제품**: 부드럽고 담백한 한입 스낵 & 저소음 데스크 케이스
- **최종 산출물**: 제품 수요 검증을 위한 반응형 랜딩 페이지 구축
- **초기 전략**: 체험단 및 사전 알림 신청을 통한 수요 검증 (CTA 중심)

## 🎨 브랜드 원칙 (Brand Principles)
- **Low Sound, Low Mess, Low Scent**: 소리, 가루, 냄새가 없는 쾌적한 오피스 라이프 지향
- **Wit & Lifestyle**: 위트 있으면서도 정돈된 오피스 라이프스타일 이미지 유지
- **Honesty**: 검증되지 않은 효능이나 가짜 후기를 사용하지 않는 정직한 브랜드

## 🤖 AI Agent Collaboration (Hermes & Codex)
이 프로젝트는 **Hermes Agent**와 **OpenAI Codex**의 협업을 통해 고도로 자동화된 개발 프로세스를 따릅니다.

| Agent | Role | Responsibility |
| :--- | :--- | :--- |
| **Hermes Agent** | **Orchestrator** | 전체 프로젝트 관리, 작업 계획 수립, 터미널 제어, 파일 편집 및 최종 검증 수행 |
| **Codex Agent** | **Specialist** | 복잡한 로직 구현, 대규모 코드 리팩토링, 고난도 알고리즘 및 기능 구현 전담 |

### 🔄 협업 워크플로우
1. **Planning**: Hermes가 프로젝트의 목표와 구조를 분석하고 작업을 세분화합니다.
2. **Delegation**: 복잡한 코딩 작업이 필요한 경우, Hermes가 Codex에게 특정 태스크를 위임(Delegate)합니다.
3. **Execution**: Codex가 코드를 작성하면, Hermes가 이를 검토하고 실제 파일에 적용하며 테스트를 수행합니다.
4. **Verification**: Hermes가 최종 결과물을 확인하고 사용자에게 보고합니다.
